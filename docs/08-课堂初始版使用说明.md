# 课堂初始版：从空页面开始实战

## 两个应用各做什么

| 应用 | 包名 | 开发地址 | 用途 |
|---|---|---|---|
| `frontend/apps/admin` | `@vben/admin` | http://localhost:5666 | 完整参考答案、成品演示 |
| `frontend/apps/starter` | `@vben/starter` | http://localhost:5667 | 课堂现场编写、学员练习 |

两者是同一个 pnpm workspace 中的独立应用，共用 packages、internal 和同一个 Go 后端，不重复安装另一套框架。使用不同的端口、应用名称和缓存命名空间，可以同时打开对照。

初始版保留：

- Vben 登录、侧栏、页签、布局、权限守卫、404 和基础样式。
- 商品管理 `/products`、任务看板 `/tasks` 两个菜单。
- 已对接 Go 的鉴权、请求拦截器及 `/api` 代理。
- `src/api/products.ts`、`src/api/tasks.ts` 中的接口函数和类型，作为课前给定契约。
- Element Plus、VueUse、dayjs、Vben useSortable 等已有依赖。

初始版的两个业务页仅显示标题与一句课堂说明。没有表格、卡片、筛选、表单、统计、业务组合函数或业务测试答案；也不会在打开空业务页时自动读取商品或任务列表。它可以正常登录和导航，空白区域就是现场实现的位置。

## 启动

先启动现有 Go 后端：

```sh
cd /Users/ethan/Desktop/full-stack-workspace/lesson-06/backend
go run .
```

如果服务已启动，无需重复启动。再开前端终端：

```sh
cd /Users/ethan/Desktop/full-stack-workspace/lesson-06/frontend
corepack pnpm install --frozen-lockfile
corepack pnpm dev:starter
```

打开 http://localhost:5667 ，使用与完整版相同的课堂账号：`admin` / `123456`（以 backend/.env 实际 ADMIN_PASSWORD 为准）。初始版与完整版分别登录，浏览器缓存互不混用。

需要同时展示完整版本时，另开终端：

```sh
cd /Users/ethan/Desktop/full-stack-workspace/lesson-06/frontend
corepack pnpm dev:admin
```

原有 `corepack pnpm dev` 和 `corepack pnpm build` 仍指向完整版；课堂初始版使用带 `:starter` 的命令。

## 从哪里写

以下路径相对于 `frontend/apps/starter/src/`：

| 文件/目录 | 当前状态 | 课堂要做什么 |
|---|---|---|
| `views/tasks/index.vue` | 只有页面标题 | 任务看板主入口，逐步加入统计、筛选和列布局 |
| `views/products/index.vue` | 只有页面标题 | 商品管理主入口，逐步加入列表、分页和表单 |
| `router/routes/modules/tasks.ts` | 已注册 | 保留任务菜单，无须重建路由 |
| `router/routes/modules/products.ts` | 已注册 | 保留商品菜单 |
| `api/tasks.ts` / `api/products.ts` | 已准备 | 阅读契约并调用，不在课堂改接口协议 |
| `views/tasks/components/` | 尚未创建 | 现场创建任务卡片、看板、抽屉 |
| `composables/` | 尚未创建 | 现场创建页面业务状态组合函数 |

完整答案在 `apps/admin/src/` 的对应路径。不要让 starter 导入 admin 的页面或组合函数，否则课堂代码会直接依赖答案。需要借用一段模板时，复制到 starter 再继续编写。

VS Code 的 `vben-admin.code-workspace` 已同时列出两个应用，打开它即可并排查看。课堂修改 `apps/starter`，完整 `apps/admin` 保持作为参考。

## 一小时怎么安排

选择任务看板或商品管理其中一条主线，直接使用 [09-从初始版实战任务看板](09-从初始版实战任务看板.md)（主讲）或 [10-从初始版实战商品管理](10-从初始版实战商品管理.md)（备选）。两份都从标题页起步，按课堂顺序给出每步文件、完整代码、原理说明和验收动作，所有现场编辑路径明确指向 starter。原 `01`、`06` 文档作为概览和成品源码说明。

初始版保留空业务页。两份学员讲义提供各阶段完整代码，配合原理说明、验证步骤与课后练习，可用于课堂跟进和独立复习。每条路线安排 55 分钟实战与验证 + 5 分钟讨论；课后可按自己的节奏逐行理解实现。

完成课堂练习后，它会成为你本次实战的版本；项目没有自动重置脚本，避免误删讲课过程中的代码。再次授课前自行保存或复制 starter。

## 检查与构建

```sh
# frontend 目录
corepack pnpm typecheck:starter
corepack pnpm build:starter
```

构建产物：`frontend/apps/starter/dist`，与完整版的 dist 分开。当前初始版没有业务逻辑，未额外增加空页面单元测试。登录与两个菜单需通过真实 Go 服务验收；单独部署 dist 时仍需配置同源 `/api` 代理。

## 数据边界

两个前端只隔离代码和浏览器状态，**不隔离数据库**。学员后续接入新增、编辑、删除接口后，两个应用会看到同一份数据。课堂操作使用新建的 CLASS-* 测试记录；不要为了恢复初始页面而清空数据库。
