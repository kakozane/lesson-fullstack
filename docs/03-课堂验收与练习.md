## 课堂练习（分层选择）

### 练习 A：库存提醒（10 分钟）

把库存低于 20 的商品改成警告标签，0 库存显示“缺货”。只改展示，不修改商品上下架状态。

验收：0、19、20 三个边界显示正确；颜色之外仍保留可读文字。

### 练习 B：保存后定位新商品（15 分钟）

当前保存后沿用筛选条件，因此新商品可能不满足筛选而不可见。设计一个明确的“查看新商品”交互，先说明应如何处理用户原来的筛选，再实现。

验收：保存成功与列表可见性分开处理；不让用户误以为保存失败。

### 练习 C：将筛选写入 URL（20 分钟）

把 keyword、category、status、page 写到路由查询参数，并支持刷新还原。

验收：status=0 不丢；非法页码回到 1；浏览器前进后退正常；不出现双向 watch 循环。

### 练习 D：增加请求取消（20 分钟）

为列表请求引入 AbortController，旧请求被取消时不展示错误消息。保留最新请求保护，解释两种机制的作用。

验收：快速查询不闪错误消息；loading 只由当前请求结束；离开页面后释放请求。

## 常见故障

### pnpm 版本错误

进入 frontend 后使用 `corepack pnpm`，不要从其他目录借用不同版本 pnpm。依赖已锁定，不要为了启动随意升级 Vben 或 Vite。

### 5666 / 8080 被占用

先检查占用进程，不终止不相关服务。需要换端口时：前端修改 apps/admin/.env.development 的 VITE_PORT；后端修改 .env 的 HTTP_ADDR，同时更新 apps/admin/vite.config.ts 的 proxy target。

### 数据库连接失败

确认 Docker mysql 运行、3306 映射存在、backend/.env 的账号密码正确。检查目标库名只含小写字母、数字和下划线。不要把 .env 内容截图投屏或贴到问题反馈中。

### 接口返回 404 或 HTML

确认 Vite 代理仍指向本地 Go，VITE_NITRO_MOCK=false。浏览器请求应为 `/api/products`；代理保留 `/api` 前缀。修改 Vite 配置后重新启动前端。

### 重启 Go 后登录失效

这是内存会话的预期行为，重新登录即可。课堂不讲分布式会话和 refresh token。

### 修改后列表没看到商品

先确认保存成功，再检查当前关键词、分类、上下架条件及页码。保存后按原条件刷新；新商品不一定匹配旧筛选。

### 主题和菜单仍显示旧模板

本项目使用独立缓存命名空间 lesson-06-products。若修改 preferences 后旧设置仍存在，在浏览器中清除该本地站点存储后重新登录；不要清空其他站点数据。
