# Gin + GORM 商品模块联调验证记录

> 本记录是新增任务看板前的商品模块验收。任务模块追加后的验证及数据核对见 `07-任务接口与验收.md`，不要把下文“本轮仅文档修改”理解为后续未新增功能。

验证日期：2026-10-28。环境：本机 Docker MySQL、Go 1.26.2、Node 24、pnpm 11.4.0、桌面 Chrome。

本记录对应当前 Gin + GORM 版本，替代初版 net/http 的验收记录。浏览器访问 `http://localhost:5666`，请求经 Vite `/api` 代理进入 `http://127.0.0.1:8080`，使用真实 MySQL，无商品 Mock。本轮未发现需要修改业务代码的问题，修改集中在课程文档对齐。

## 数据保护与清理

- 开始前保存原有 37 条商品的完整 API 快照，包括 updatedAt。
- 浏览器验收单独创建 11 条 QA-GIN-1028-R1-* 商品，所有写入、上下架和删除仅作用于这组数据。
- 真实接口回归另建独立 SMOKE-* 数据，各次运行结束自动清理。
- 完成后清理剩余 QA 商品，重新查询并逐项对比：原有 37 条商品的全部返回字段和时间戳一致。
- CLASS-DEMO-01 是此前保留的课堂示例，未修改；36 是全新库首次初始化的种子数量，当前总数为 37。
