# 任务看板接口与验证记录

## 访问与数据模型

菜单：任务看板；路由 `/tasks`。API 前缀 `/api`，所有任务接口沿用 Bearer 鉴权及 `{code,data,message}` 响应。成功 HTTP 200 / code=0，失败使用对应 HTTP 状态码。

由 `backend/bootstrap/task_migration.go` 初始化 `tasks`、`task_board_meta` 两张表，执行入口为 `bootstrap.InitializeApp`。`lesson_migrations` 版本 2 控制 9 条任务种子的首次插入；已有商品表和版本 1 不重置。日期相对首次初始化当天生成，后续重启不自动刷新。

这是单看板、全量加载的课堂实现，最多 200 条任务。负责人是最多 30 字的姓名文本，不代表用户系统或授权关系。

### 字段

| 字段 | 约束 |
|---|---|
| id | 服务端生成，正整数 |
| title | trim 后 1～80 字 |
| description | trim 后最多 2000 字，可以为空 |
| assignee | trim 后最多 30 字，可以为空（待分配） |
| priority | low / medium / high |
| status | todo / doing / done |
| dueDate | 空字符串或真实日历日期 YYYY-MM-DD |
| updatedAt | 响应字段，YYYY-MM-DD HH:mm:ss |
| version | 看板版本，正整数，所有修改必须带上当前值 |

数据库 position 是内部排序字段，不由表单提交。GET 和所有成功写入返回同一快照结构：

```json
{
  "code": 0,
  "data": {
    "version": 1,
    "items": [{
      "id": 1,
      "title": "梳理需求",
      "description": "明确交付与验收标准",
      "assignee": "林悦",
      "priority": "high",
      "status": "todo",
      "dueDate": "2026-10-30",
      "updatedAt": "2026-10-28 14:00:00"
    }]
  },
  "message": ""
}
```

items 在每个状态内部按 position、id 排序，前端按 status 分组。顶部统计基于全部 items；筛选只影响列内可见任务。

## 路由

| 方法 | 路径 | 请求 |
|---|---|---|
| GET | /tasks | 无参数，完整看板快照 |
| POST | /tasks | TaskInput + version |
| PUT | /tasks/:id | 全部 TaskInput 字段 + version |
| PATCH | /tasks/:id/move | status + beforeId + version |
| DELETE | /tasks/:id | JSON 请求体 `{version: 当前版本}` |

新增/编辑示例：

```json
{"title":"完成交互设计","description":"确认空态与失败反馈","assignee":"陈晨","priority":"medium","status":"todo","dueDate":"2026-10-30","version":1}
```

移动示例：

```json
{"status":"doing","beforeId":6,"version":2}
```

表示把 URL 中的任务放到进行中列、ID=6 之前；beforeId=0 表示追加末尾。同列移动也用此接口。beforeId 必须属于目标列且不能是任务自己。表单修改 status 时自动追加到目标列末尾，同状态编辑保留位置。

### 并发与失败

所有增删改、拖拽都在事务内锁定 `task_board_meta` 的同一行，校验 version，再写入并递增版本。过期版本返回 409，整次操作不生效。成功响应在同一事务中生成最新快照。

- 400：字段、日期、版本格式、移动目标不合法。
- 401：会话失效；重启 Gin 后重新登录。
- 404：任务不存在。
- 409：版本冲突，或超过 200 条任务限制。
- 500：数据库或服务器故障。

新版本未被其他客户端自动推送；其他页面点击刷新或下一次写入遇到 409 时才同步。编辑冲突保留草稿，用户核对后可再次提交。时间戳不替代 version。

## 尚未覆盖与教学边界

未做手机真机触控、完整跨浏览器、生产反向代理部署和负载测试；空列拖放的数组逻辑有单测，本轮未额外清空种子列做手工拖放测试。移动期间通过按钮禁用和组合函数测试验证重复提交保护，没有做真实多用户压力测试。

没有增加多项目、权限分配、附件、富文本、提醒推送、实时协同、导入导出。单管理员课堂任务可自由切换三个状态，不包含审批流。公网使用前需要独立设计这些边界。
